**제목**

```
문자 발송 개선 — 수신자별 결과 확인과 중복 발송 방지
```

**한 줄 요약**

```
문자를 여러 명에게 보낼 때 누구에게 성공하고 실패했는지 바로 확인할 수 있고, 다시 보내면 실패한 분에게만 발송되며, 버튼을 여러 번 눌러도 같은 문자가 중복 발송되지 않습니다.
```

**상세 내용**

```
[주요 변경]
- 일괄 문자 발송 후 수신자별로 성공/실패가 표시됩니다.
- 재전송 시 실패한 수신자에게만 다시 발송됩니다. 이미 받으신 분께 중복 발송되지 않습니다.
- 전송 버튼을 연속으로 누르거나 네트워크가 불안정해도 같은 문자가 두 번 나가지 않습니다.
- 전송 중에는 버튼이 잠겨 진행 상태를 알 수 있습니다.
- 장문(LMS) 전환 기준이 모든 화면에서 동일하게 적용되고, 최대 길이를 넘긴 메시지는 발송 전에 안내됩니다.
- 발신번호는 기관에 등록된 번호만 사용할 수 있습니다.

[버그 수정]
- 원인: 입원상담 화면의 문자 전송 버튼에 잠금이 없어 연속 클릭 시 같은 문자가 여러 번 발송될 수 있었습니다.
- 해결: 발송 요청에 고유 키를 부여해 중복 요청을 서버에서 차단하고, 전송 중 버튼을 잠급니다.

[운영 안내]
- 입원상담 화면의 예약발송 기능은 사용 이력이 없어 화면에서 제외했습니다.
- 비밀번호 재설정 인증문자도 발송 이력에 기록됩니다(인증번호 자체는 기록되지 않습니다).
- 발송 결과가 확인되지 않은 건은 "결과 확인 중"으로 표시됩니다.
```
